NEW AXE NET 1.44.0 · PROFESSIONAL UX RELEASE

핵심 수정
1) 한글 검색 자모 분리 문제
- 정보 / 멤버 / 자산·계좌 / 무법지대 / AXE TUBE 검색에 IME 조합 보호 적용
- composition 중에는 상태 렌더를 막고, 220ms debounce 후 검색 반영
- 검색창 포커스/커서 위치도 렌더 후 복원

2) AXE TUBE 영상 재생 초기화 문제
- 추천/비추천, 댓글 로딩·등록·수정·삭제 때 전체 화면을 다시 그리지 않음
- 같은 영상이면 상세 body만 갱신하고 YouTube iframe은 유지
- 재생 위치와 재생 상태가 액션 때문에 초기화되지 않도록 구조 변경
- 댓글 작성 중 다른 액션이 발생해도 작성 중 텍스트를 최대한 보존

3) 바로가기 가시성 강화
- 상단 QUICK ACCESS 버튼을 주요 유틸리티 액션으로 승격
- 드롭다운 항목에 기능 마크/세부 위치/화살표 추가
- 홈 바로가기를 작은 pill에서 2~3열 운영 런처 카드로 변경

4) 전체 고급화
- 브랜드 쉘 / 카드 / 포커스 / 검색창 / 모달 / 스크롤바 / hover 계층 통일
- 과한 네온 대신 전문 운영 포털 느낌으로 정리
- 사용되지 않는 legacy settingsView.js 제거

검증 완료
- 전체 JS node --check PASS
- npm run audit:styles PASS
- npm run audit:ux PASS
- 상대경로 import graph PASS

참고
- 이 작업 환경에서는 업로드 ZIP의 node_modules가 Windows 중심 optional binary를 포함하고 있어 Vite production build 자체는 실행 검증하지 못했습니다.
- 소스 문법/구조/audit는 통과했으며, GitHub/Vercel 배포 시 의존성을 정상 설치하면 기존 방식대로 build하면 됩니다.

권장 배포
1. 기존 NEW-AXE-NET 저장소를 백업/커밋
2. 전체 소스 ZIP 기준으로 파일 교체
3. src/modules/fund/views/settingsView.js가 저장소에 남아 있다면 삭제
4. .env는 기존 Vercel Environment Variables를 그대로 사용 (ZIP에 실 .env는 포함하지 않음)
5. npm install
6. npm run audit:styles
7. npm run audit:ux
8. npm run build
9. Git push → Vercel 자동 배포
