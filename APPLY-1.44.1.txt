AXE NET 1.44.1 HOTFIX

증상
- 무법지대 기록/공략/브리핑맵 일부 버튼 동작 안 함
- Console: ReferenceError: searchFocus is not defined
- 공금내역 상세/수정창이 화면 중앙이 아니라 콘텐츠 아래/오른쪽 기준에 고정됨

원인
1) 1.44.0 IME 한글 검색 보강 시 outlaw/assets의 bindEvents() 안에서
   render 함수 지역변수 searchFocus를 직접 참조해 ReferenceError 발생.
   무법지대에서는 이 지점 이후의 기록/공략/맵 이벤트 바인딩이 전부 중단됨.
2) Professional 진입 애니메이션의 transform이 fixed 모달의 containing block에 영향을 줄 수 있었음.

적용 방법
- GitHub 프로젝트에 HOTFIX ZIP의 파일을 같은 경로로 덮어쓰기
- 삭제 파일 없음
- Supabase SQL 변경 없음
- 환경변수 변경 없음

검증
1) npm run audit:styles
2) npm run audit:ux
3) npm run build

배포 후 확인
- 무법지대 > 통계 > 기록 버튼
- 무법지대 > 공략 > 지역/단계 선택 및 관리자 버튼
- 무법지대 > 브리핑맵 > 맵 선택 및 관리자 버튼
- 자산·계좌 검색 한글 입력
- 공금 > 공금내역 > 상세창이 viewport 중앙 부근에 표시되는지
