# NEW AXE NET v1.13.0

기존 AXE NET 공금 관리자 운영 기능을 NEW 구조로 묶어서 이관한 **관리자 패리티 2차** 버전입니다.

## v1.13.0 핵심
- 공금내역
  - 기존 검색/필터/수정/삭제/복구 유지
  - 공용계좌·회사잔고 변화 요약
  - 납부 직접등록 / 수입·지출·조정 등록
  - 직접등록 시 증빙 파일첨부 / Ctrl+V / 드래그앤드롭
  - 등록된 증빙은 공금내역에서 바로 크게 보기
  - 관리자 쓰기 작업은 프론트에서 동시 중복 실행을 잠그고 DB 제약으로 2중 방어
- 잔액점검
  - 사이트 계산 잔액 ↔ 인게임 실제 잔액 비교
  - 잔액점검 증빙 첨부 및 이력 증빙 보기
  - 최근 대조 결과와 계좌별 차이를 한 화면에서 확인
- 요율관리
  - 적용 시작 주차 기준 주간 공금 금액 등록
  - 활성/비활성 이력 관리
- 면제관리
  - 선택 주차 기준 멤버 면제 등록/해제
- 정합성점검
  - 브라우저 계산이 아니라 Supabase 원본 RPC에서 직접 점검
  - 중복 납부 / 승인원장 누락 / 검수대기+납부 충돌 / 연결 신청 없는 원장
- 공금 멤버관리
  - 회원 데이터를 복제하지 않고 `fund_member_settings`에 공금 전용 예외만 저장
  - 공금 대상 포함/제외
  - 공금 계산용 가입일 보정
  - 운영 메모
  - 실제 닉네임·퇴사·Discord 연결은 기존 멤버 모듈이 계속 단일 원본

## UI 구조
관리자 패리티 화면 전용 스타일은 `src/modules/fund/views/admin.css`로 분리했습니다.
기존 `fund.css` 아래에 버전별 override를 계속 누적하지 않습니다.

내 제출 / 검수대기 증빙 썸네일은 화면을 꽉 채우는 미리보기로 변경하고, 클릭 시 기존 라이트박스에서 전체 이미지를 확인합니다.

## 적용
1. Supabase SQL Editor에서 `supabase/018_fund_admin_parity.sql` 전체 실행
2. v1.13.0 ZIP을 기존 NEW AXE NET 프로젝트에 덮어쓰기
3. GitHub Desktop Commit / Push
4. Vercel 자동배포

## 환경변수
추가 환경변수 없음. 기존 값을 그대로 사용합니다.
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (Vercel 서버 전용)

## CSV
추가 Import 없음.

## v1.14.0 — Compact Admin System

기능 추가보다 관리화면 구조를 먼저 정리한 리팩터링 버전입니다.

### 구조 변경
- `views/admin.css`를 기존 v1.13 전용 규칙에서 **공통 Compact Admin System**으로 전면 재작성
- 버전 번호가 붙은 `.fund-admin13-*` 클래스 제거
- 공금 관리자 화면은 앞으로 `.fund-admin-*` 공통 규격을 사용
- 화면별 padding/폭 override를 계속 덧붙이는 방식 중단
- 기본 행 높이, 컨트롤 높이, 컬럼 간격, 패널 간격을 CSS 변수에서 통합 관리

### 공금내역
- 회사잔고 변화 / 합계 변화 KPI 제거
- `공용계좌 현재 잔액 / 현재 필터 공용계좌 변동 / 표시 내역`만 상단에 표시
- 날짜·내역·계좌·금액·증빙·상세 컬럼을 필요한 폭만 사용하도록 재배치
- 넓은 화면에서도 컬럼 사이가 과도하게 벌어지지 않게 변경

### 잔액점검
- 공용계좌를 메인 KPI로 승격
- 회사잔고는 보조 카드/보조 입력으로 축소
- 총합 KPI 제거
- 점검 이력도 공용 차이를 먼저 읽도록 정리

### 멤버관리
- 한 행마다 날짜 input / 메모 input / 저장 버튼을 모두 노출하던 구조 제거
- 기본 행은 `멤버 / 대상여부 / 가입일 / 주차상태 / 설정`만 표시
- 예외가 필요한 멤버만 `설정`을 펼쳐 기준일 보정·메모를 수정

### 정합성 / 요율 / 면제
- 동일한 Compact Admin 규격으로 이관
- 정상 항목의 불필요한 세로 여백 축소

### 적용
추가 SQL 없음. 기존 프로젝트에 덮어쓰기 후 Commit → Push → Vercel 배포만 하면 됩니다.


## v1.15.0 — Compact Admin System v2

이번 버전은 기능 추가가 아니라 관리자 UI의 폭/밀도 설계를 다시 고친 구조 리팩터링입니다.

- admin.css 전체 교체: 이전 규칙에 override를 추가하지 않음
- 관리자 화면 폭 프리셋: wide / medium / narrow
- 공금내역 컬럼에서 1fr 제거, 실제 필요한 고정 폭 사용
- 요율관리: 좌우 2분할 제거 → 컴팩트 세로형 폼 + 이력
- 정합성점검: 긴 원장 ID 기본 숨김, 필요할 때만 펼쳐보기
- 정상 정합성 섹션은 작은 한 줄 패널로 축소
- 멤버관리/잔액점검/면제관리 패널 최대폭 제한
- 카드가 화면 폭을 억지로 채우지 않도록 metric 폭 고정
- 추가 SQL 없음 / CSV 없음


## v1.16.0 — AXE UI SYSTEM 1.0

기존 AXE NET을 UI/UX 기준서로 삼아 NEW AXE NET의 공통 디자인 수치를 코드화했습니다.

- `src/styles/axe-ui-system.css`: 전역 UI 토큰
- `docs/AXE_UI_SYSTEM_1.0.md`: UI 기준 문서
- 공금 관리자 `admin.css`: 전면 재작성
- 월별현황 `overview.css`: AXE NET 밀도 기준으로 전면 재작성
- 공금 공통 폰트/버튼/입력/탭 크기를 AXE NET 기준으로 보정
- 작은 글씨로 억지로 압축하지 않고 열 폭과 간격으로 컴팩트함을 확보

### DB
추가 SQL 없음.

### 적용
기존 NEW-AXE-NET 폴더에 전체 덮어쓰기 후 Commit → Push → Vercel 자동배포.


### AXE UI SYSTEM 1.0
공금 UI는 기존 AXE NET의 실제 글자/컨트롤/표 밀도를 기준으로 재설계했습니다. 컴팩트함을 위해 8~9px 글씨를 사용하는 방식은 제거하고, 열 폭·gap·padding으로 밀도를 관리합니다.
