# NEW AXE NET v1.12.0

기존 AXE NET 공금 운영 흐름을 NEW 구조로 묶어서 이관한 패리티 버전입니다.

## 이번 묶음
- 공금납부: 증빙 이미지 필수, 파일첨부, Ctrl+V 붙여넣기, 드래그앤드롭
- 증빙 3MB 제한 + 큰 이미지 자동 최적화
- 공용계좌 / 회사잔고 / 분할납부
- 관리자 대리제출
- 내 제출: 증빙 미리보기, 분할 상세, 검수 결과
- 검수대기: 카드에서 증빙 바로 확인, 승인/거절
- 승인 시 요청의 분할 금액과 증빙이 원장에 그대로 연결
- 증빙은 public URL이 아닌 Supabase private Storage `fund-evidence` 사용

## 적용
1. Supabase SQL Editor에서 `supabase/017_fund_submit_parity.sql` 전체 실행
2. v1.12.0 ZIP을 기존 프로젝트에 덮어쓰기
3. GitHub Desktop Commit / Push
4. Vercel 자동배포

## 환경변수
v1.11에서 추가한 `SUPABASE_SERVICE_ROLE_KEY` 그대로 사용합니다. 새 환경변수는 없습니다.

## v1.12.1 — 공금납부 / 내 제출 / 검수대기 UI 마감 1차

기능 및 DB 변경 없이 v1.12의 세 화면을 기존 AXE NET의 운영 밀도와 NEW AXE 브랜드 테마에 맞게 정돈했습니다.

- 공금납부
  - 로그인 본인확인 영역을 작은 계정 칩 형태로 압축
  - 납부방식 셀렉트를 AXE 테마로 정리
  - 증빙 첨부영역 크기/미리보기 개선
- 내 제출
  - 세로로 늘어진 카드 → `증빙 썸네일 + 핵심정보` 2열 카드
  - 증빙을 고정 크기로 보여 이미지 비율 때문에 얇게 찌그러져 보이던 현상 해결
  - 제출/검수 정보를 사실표 형태로 정리
- 검수대기
  - 증빙을 크게 확인하면서 승인/거절할 수 있는 카드 구조
  - 검수대기는 왼쪽 AXE 골드 라인으로 강조
- 증빙
  - 썸네일 클릭 시 사이트 안에서 크게 보는 라이트박스 추가
  - ESC / 배경 클릭 / X 버튼 닫기 지원
- 코드
  - 기존 v1.12 UI CSS 블록을 통째로 교체하여 누적 override 없이 정리

추가 SQL 없음.
