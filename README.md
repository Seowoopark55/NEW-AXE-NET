# NEW AXE NET v1.6 — AXE NET 공금 Parity 1차

이번 버전부터 공금의 화면/기능 구성 기준을 기존 AXE NET으로 고정합니다.

## 핵심 방향
- NEW AXE NET을 새 디자인으로 만드는 것이 아니라 기존 AXE NET의 운영 경험을 계승
- 차이는 내부 구조: Supabase-first / 모듈화 / RPC 권한 / 감사로그 / 실시간 계산
- 사용자에게 보이는 명칭과 공금 운영 순서는 기존 AXE NET 우선

## v1.6 변경
### 공금관리 상단
기존 AXE NET 스타일로:
- 공금관리
- 공용계좌 계산 잔액
- 전체 검수대기
- 선택월 승인 건
- 선택월 면제
- 탭형 메뉴

### 탭 구성
일반:
- 월별현황
- 공금납부
- 내 제출

관리자:
- 검수대기
- 공금내역
- 잔액점검
- 요율관리
- 면제관리
- 정합성점검
- 멤버관리

### 월별현황
기존 AXE NET처럼 `멤버 x 주차` 표 구조로 변경:
- 완료
- 검수대기
- 미납
- 면제
- 예정/가입 전
- 멤버별 미납 횟수

회차는 일요일~토요일이며 토요일이 속한 달을 표시 월로 사용합니다.

### 정합성점검
1차 자동점검:
- 동일 멤버/주차 중복 활성 납부
- 승인 신청이 있는데 활성 납부내역이 없는 경우
- 검수대기 요청인데 이미 활성 납부가 있는 경우

### 멤버관리
공금 대상 멤버의:
- 닉네임
- 가입일
- Discord 연결 여부
- 선택 주차 상태
를 한 화면에서 확인합니다.

## 적용
1. Supabase SQL Editor에서 `supabase/014_fund_axe_parity.sql` 전체 실행
2. ZIP을 기존 NEW-AXE-NET 폴더에 덮어쓰기
3. GitHub Desktop Commit
4. Push
5. Vercel 자동 배포
