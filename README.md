# NEW AXE NET v1.13.0

기존 AXE NET 공금 관리자 운영 기능을 NEW 구조로 묶어서 이관한 **관리자 패리티 2차** 버전입니다.

## v1.13.0 핵심
- 공금내역
  - 기존 검색/필터/수정/삭제/복구 유지
  - 공용계좌·회사잔고 변화 요약
  - 납부 직접등록 / 수입·지출·조정 등록
  - 직접등록 시 증빙 파일첨부 / Ctrl+V / 드래그앤드롭
  - 등록된 증빙은 공금내역에서 바로 크게 보기
  - 관리자 쓰기 작업은 프론트에서 동시 중복 실행을 잠그고 DB 제약으로 2중 방어
- 잔액점검
  - 사이트 계산 잔액 ↔ 인게임 실제 잔액 비교
  - 잔액점검 증빙 첨부 및 이력 증빙 보기
  - 최근 대조 결과와 계좌별 차이를 한 화면에서 확인
- 요율관리
  - 적용 시작 주차 기준 주간 공금 금액 등록
  - 활성/비활성 이력 관리
- 면제관리
  - 선택 주차 기준 멤버 면제 등록/해제
- 정합성점검
  - 브라우저 계산이 아니라 Supabase 원본 RPC에서 직접 점검
  - 중복 납부 / 승인원장 누락 / 검수대기+납부 충돌 / 연결 신청 없는 원장
- 공금 멤버관리
  - 회원 데이터를 복제하지 않고 `fund_member_settings`에 공금 전용 예외만 저장
  - 공금 대상 포함/제외
  - 공금 계산용 가입일 보정
  - 운영 메모
  - 실제 닉네임·퇴사·Discord 연결은 기존 멤버 모듈이 계속 단일 원본

## UI 구조
관리자 패리티 화면 전용 스타일은 `src/modules/fund/views/admin.css`로 분리했습니다.
기존 `fund.css` 아래에 버전별 override를 계속 누적하지 않습니다.

내 제출 / 검수대기 증빙 썸네일은 화면을 꽉 채우는 미리보기로 변경하고, 클릭 시 기존 라이트박스에서 전체 이미지를 확인합니다.

## 적용
1. Supabase SQL Editor에서 `supabase/018_fund_admin_parity.sql` 전체 실행
2. v1.13.0 ZIP을 기존 NEW AXE NET 프로젝트에 덮어쓰기
3. GitHub Desktop Commit / Push
4. Vercel 자동배포

## 환경변수
추가 환경변수 없음. 기존 값을 그대로 사용합니다.
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SERVICE_ROLE_KEY` (Vercel 서버 전용)

## CSV
추가 Import 없음.
