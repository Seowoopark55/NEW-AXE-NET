# NEW AXE NET v1.7 — 월별현황 AXE NET Parity 마감 1차

이번 버전은 **기존 AXE NET의 현재 공금 월별현황 동작을 기준**으로 v1.6 화면을 한 단계 더 맞춘 버전입니다.

## 기준
- 겉과 운영 흐름: 기존 AXE NET
- 내부 구조: NEW AXE NET / Supabase-first
- 공금 회차: 일요일~토요일 7일 단위
- 회차 소속 월: 토요일 마감일이 속한 월
- 월에 따라 4주 또는 5주 자동 생성
- 현재 회차는 시작일부터 납부 대상이므로 기록이 없으면 `미납`
- 아직 시작하지 않은 회차만 `예정`

## v1.7 변경
- 월별현황 상단에 `선택 월` 기간 안내 복원
- 현재 운영 회차 안내 추가
- 현재 주차 열 전체를 은은하게 강조
- 주차 날짜 표기를 `MM/DD~MM/DD`로 통일
- 월별 표의 가입일 보조문구를 제거해 기존 AXE NET 표 밀도에 맞춤
- 상태 범례에 `예정/가입 전` 추가
- 하단에 주차 운영 기준 안내 추가
- 상태 pill 크기/밀도 미세 조정
- KST(Asia/Seoul) 기준으로 현재 주차 강조

## SQL
**이번 버전은 SQL 실행이 없습니다.**

기존 v1.6에서 `014_fund_axe_parity.sql`까지 적용되어 있으면 추가 DB 작업 없이 파일만 덮어쓰면 됩니다.
