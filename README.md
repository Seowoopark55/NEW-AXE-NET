# NEW AXE NET v0.7

관리자 멤버 수정 이력(Audit Log)을 추가한 버전입니다.

## v0.7 기능
- 관리자에 의한 멤버 수정 자동 기록
- 기록 항목:
  - 닉네임
  - 권한
  - 상태
  - 배지
  - 포인트
  - 퇴사일
- 누가 수정했는지 관리자 닉네임 기록
- 수정 시간 기록
- 변경 전 → 변경 후 값 기록
- 관리자 상세 패널에서 최근 20건 확인
- 일반 사용자는 audit table 조회 불가

## 적용 순서
1. Supabase SQL Editor에서 `supabase/005_member_audit.sql` 전체 실행
2. ZIP 내용을 기존 NEW-AXE-NET 폴더에 덮어쓰기
3. GitHub Desktop → Commit → Push
4. Vercel 자동 배포
5. 관리자 로그인 후 멤버 값을 하나 수정
6. 상세 패널 하단 `최근 변경 이력` 확인

## 참고
이 SQL을 실행하기 전에 있었던 과거 변경은 자동 복원되지 않습니다.
v0.7 적용 이후의 변경부터 기록됩니다.
