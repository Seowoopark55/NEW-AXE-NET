# NEW AXE NET v0.6.1

멤버 목록 카테고리/검색 결과의 순번 표시 수정 버전입니다.

## 수정사항
- 기존: 전체 멤버의 `sort_order`를 목록 순번으로 그대로 표시
- 변경: 현재 화면에 표시된 결과 기준으로 1, 2, 3... 재번호 부여
- 상태 필터뿐 아니라 검색 결과에서도 순번이 연속적으로 재계산됩니다.
- 상세 패널의 실제 DB 정렬 값은 `전체 정렬 순서`로 이름을 바꿔 구분합니다.

예:
퇴사 필터에서 기존 `4, 7, 11, 13, 18, 20`
→ `1, 2, 3, 4, 5, 6`

## 적용
1. ZIP 내용을 기존 `NEW-AXE-NET` 폴더에 덮어쓰기
2. GitHub Desktop → Commit
3. Push
4. Vercel 자동 배포

이번 버전은 DB 변경이 없으므로 Supabase SQL 실행은 필요 없습니다.
