NEW AXE NET v1.0 공금 실시간 계산 엔진 검증
=============================================

검증 기준:
- 기존 fund_status 324행
- NEW 계산 로직을 Python으로 동일 규칙 재현 후 전 행 비교

결과:
- 324 / 324 일치
- 불일치 0건

확정된 주차 규칙:
- 각 월의 토요일을 1주차, 2주차 ... 로 계산
- 해당 주는 일요일~토요일
- 예: 2026년 8월
  1주차 종료 8/1
  2주차 종료 8/8
  3주차 종료 8/15
  4주차 종료 8/22
  5주차 종료 8/29

상태 계산 우선순위:
1. 아직 시작하지 않은 미래 주차 → 예정
2. 가입일이 해당 주차 종료일보다 늦음 → 가입 전
3. 해당 주차 enabled 면제 존재 → 면제
4. 해당 주차 active payment 원장 존재(amount > 0) → 완료
5. 그 외 → 미납

금액:
- 예정 / 가입 전 → 0원
- 완료 / 미납 / 면제 → 해당 주차 fund_fee_rules 금액

중요 검증 포인트:
- 화윤 2026년 8월 1주차는 당시 주간 공금이 20,000원이지만
  active payment 10,000원 한 건으로 기존 상태가 '완료'였습니다.
- 따라서 기존 AXE NET의 실제 계산 규칙은
  '납부 합계 >= 주간 공금'이 아니라
  '해당 주차에 active payment가 존재하는가'였고,
  이 규칙을 적용했을 때 324행 전부 정확히 일치했습니다.

v1.0부터 화면 계산 원본:
- new_axe_net.members
- new_axe_net.fund_fee_rules
- new_axe_net.fund_exemptions
- new_axe_net.fund_ledger
