# 스킬랭크 데이터 보강 · 2026-08-26

사용자가 제공한 게임 내 스킬랭크 포인트 표를 기준으로 갱신합니다.

## 반영 원칙
- 숫자가 보이는 셀만 기존 데이터에 덮어씁니다.
- 빈칸은 기존 값을 보존합니다.
- `-`는 숫자 요구량이 확인되지 않은 것으로 보고 새 숫자 행을 만들지 않습니다.
- 빨간 `10SP??` 두 항목은 10SP로 유지하면서 `재확인 필요` 메모를 붙입니다.
- `A → 9`에서 수련서가 필요한 항목은 `note`에 `수련서 3장 추가 필요`를 저장합니다.
- 이미지의 `제련`은 기존 AXE NET 표기 `재련`을 유지합니다.

`supabase/046_skill_rank_update_20260826.sql`
