# NEW AXE NET v1.26.0 — INFO MODULE 1.0

## 목적
기존 AXE NET의 `정보` 영역을 NEW AXE NET의 Supabase-first 구조로 이관합니다.

## 메뉴
- 제작
- 퀘스트
- 가공·재련
- 개조서
- 스킬랭크

## 데이터 기준
사용자가 제공한 실제 AXE NET CSV를 그대로 기준으로 사용했습니다.

- 제작목록 32건
- 제작재료 95건
- 재료레시피 2건
- 퀘스트 30건 (원본에서 실제 항목이 비어 있는 빈 자리 17행은 제외)
- 가공·재련 8건
- 개조서 207건
- 스킬랭크 96건

`제작랭크` 별도 테이블은 만들지 않습니다. 제작 아이템의 요구랭크는 `제작목록.craft_rank`, 제작 스킬 승급 정보는 `스킬랭크`의 `skill=제작` 행을 기준으로 사용합니다.

## UI / 기능
### 제작
- 분류 필터
- 아이템명/재료명 검색
- 목록/상세 분리
- 요구 제작랭크, 성공률, 획득처
- 제작재료 표시
- 재료레시피가 있는 재료는 하위 제작식 표시
- 제작 스킬랭크 요약 표시

### 퀘스트
- 직업 필터
- 검색
- 요구수량 / 랭크 / 보상금 / 경험치 / 메모

### 가공·재련
- 직업 필터
- 검색
- 투입재료 → 결과수량
- 퀘스트 요구수량 / 보상금 / 경험치

### 개조서
- 접두/접미, 분류, 부위 필터
- 이름/옵션 통합검색
- 목록/상세 분리
- 적용 부위 / 옵션 / 성공률 / 메모
- 최근 거래가 / 거래일 / 등록자
- 팀원 로그인: 최근 거래가 갱신
- 팀원 로그인: 개조서 등록신청 + 내 신청 확인
- 관리자: 신청 승인/반려
- 관리자: 정식 개조서 직접 등록/수정/목록 내리기

개조서 분류·부위·옵션 입력 후보는 실제 정식 개조서 데이터에서 파생합니다. 별도의 옵션·분류 원본 시트가 제공되지 않았으므로 존재하지 않는 분류 사전을 임의로 만들지 않았습니다.

### 스킬랭크
- 스킬 필터
- 검색
- 랭크 전환 / 필요 포인트 / 포인트 종류

## 보안
- 정보 조회: Supabase 공개 읽기 뷰
- 관리자 개조서 변경: Supabase Auth + `is_admin()` RPC 검증
- 팀원 개조서 신청/가격갱신: HttpOnly 멤버 세션을 검증하는 `/api/member-session` 경유
- 브라우저에서 임의 nickname/member_key를 제출해 권한을 가장하지 않음

## 스타일
AXE STYLE 4.0을 그대로 사용합니다.
- 정보량만큼만 폭을 사용
- 제작: 약 780px
- 퀘스트/가공·재련: 약 720px
- 개조서: 약 850px
- 스킬랭크: 약 650px
- 데스크톱 저밀도 행에 빈 공간을 만들기 위한 `1fr` 사용 금지
- 모듈 CSS는 `src/modules/info/info.css`가 단독 소유

## SQL 적용 순서
1. `023_info_module.sql`
2. `024_info_data_import.sql`

024는 legacy key 기반 UPSERT이므로 재실행해도 동일 원본 행이 중복 생성되지 않습니다.
