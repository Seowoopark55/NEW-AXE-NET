# AXE 개조서 추천세팅 1.0

## 목적
팀원들이 실제로 사용해 본 개조서 조합을 장비창 형태로 빠르게 확인합니다.

## 표현 규칙
- 특정 의상 이름은 표시하지 않고 `겉옷 / 상의 / 하의 / 신발`만 사용합니다.
- 장비 이미지는 모두 무채색으로 통일합니다.
- 옵션은 최대 수치를 본문에 강조하고 실제 등장 범위를 괄호로 같이 표시합니다.
- 접두와 접미 색상을 구분하며 디버프 옵션은 붉게 표시합니다.
- PC: hover/focus, 모바일: slot tap으로 확인합니다.

## 데이터 구조
추천 조합 자체는 `src/modules/info/modbookPresets.js`에 저장합니다.
개조서 이름/type만 지정하고 실제 옵션/범위는 기존 Supabase `info_modbooks_app` 데이터에서 찾아 표시하므로 옵션 원본을 중복 저장하지 않습니다.

## 첫 프리셋
`이동속도 1티어`는 초기 AXE 추천 초안입니다. 실사용 의견에 따라 조합을 바꾸면 됩니다.

## 향후 수정
새 프리셋을 추가할 때는 `MODBOOK_PRESETS` 배열에 preset object 하나만 추가하면 UI가 자동으로 선택 카드와 장비 슬롯을 생성합니다.
