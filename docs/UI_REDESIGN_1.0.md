# NEW AXE NET v1.41.0 · UI / IA REDESIGN

## 목표
실사용 기능 이전이 끝난 뒤 NEW AXE NET을 기능 목록형 관리자 화면에서 AXE 브랜드 운영 포털 형태로 정돈한다.

## 1차 메뉴 구조
- 홈
- 소식
- 정보
- 콘텐츠
- 운영

### 2차 메뉴
콘텐츠
- 무법지대
- AXE TUBE

운영
- 공금
- 자산·계좌
- 멤버

공지사항/정보 내부의 세부 탭은 기존 모듈 탭을 그대로 사용한다.

## 홈
숫자 KPI, 운영현황, 바로가기 카드 위주의 긴 대시보드를 제거하고 다음 미리보기만 남긴다.
- 최근 공지 3건
- 최근 공금 흐름 4건
- 최근 AXE TUBE 3건

홈 컨테이너는 배너/상단 카테고리와 같은 사이트 축을 사용한다.

## AXE TUBE
- 영상/조회/추천/분류 요약 KPI 제거
- Runtime Primary 기술 안내 제거
- 관리자 운영 상태 패널 제거
- 검색 + 분류 + 정렬 다음에 바로 영상 콘텐츠 시작
- 카드 제목/작성자/메타 텍스트 크기 상향

## 배너
기존 로고 이미지를 카드 안에 얹는 방식 대신 이미 포함된 `axe-hero-premium.webp`를 전체 배너로 사용한다.
- 2240×320 원본 비율을 활용한 와이드 배너
- 다크 오버레이와 얇은 스캔라인만 추가
- 좌하단 브랜드 카피만 최소 노출

## 공통 정렬
- 사이트 폭: 1120px
- 운영 워크스페이스: 960px
- 공지/정보의 페이지 헤더와 탭 기준선을 960px 축으로 정리
- 공지 목록도 탭과 같은 폭을 사용하여 계단식 인상을 제거

## DB / API
변경 없음. UI/내비게이션 재구성만 포함한다.
