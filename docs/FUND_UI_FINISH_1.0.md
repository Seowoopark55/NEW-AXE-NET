# FUND UI FINISH 1.0

## 사용자 용어

- `공금내역`: 공금 전체 수입·지출·납부 흐름을 보는 메뉴명
- `공금기록`: 시스템에 실제로 반영된 공금 데이터의 사용자용 표현
- `납부기록`: 멤버별 주간공금 승인으로 반영된 기록
- `ledger / fund_ledger`: DB/API 내부 기술명. 사용자 화면에는 노출하지 않음

## 화면 원칙

- 검수대기: 한 신청 = 하나의 검수 블록. 정보/액션 분리.
- 공금내역: 날짜 그룹 기반 운영기록. 액션은 작고 명확하게.
- 면제관리: 등록 폼과 활성 목록을 구분하고 목록은 2줄 이하.
- 정합성점검: 문제 카테고리 우선, 세부 ID는 필요할 때만 펼침.
- 멤버관리: 공금 대상 여부와 상태 중심. 회원 원본 정보는 멤버 메뉴에서 관리.
