# AXE Operations Console 1.0

## 목적

AXE NET의 반복적인 폭/간격/카드 밸런스 보정을 줄이기 위해 업무 UI를 데이터 중심 운영 콘솔로 재설계한다.

## 고정 원칙

- 전체 앱은 상단바 + 중앙 워크스페이스 구조를 사용한다.
- 화면의 시각적 중심을 좌측 사이드바가 밀지 않는다.
- 대형 Hero는 업무 화면에서 사용하지 않는다.
- KPI는 큰 카드보다 inline stat rail을 우선한다.
- 한 화면에 여러 panel card를 중첩하지 않는다.
- 표는 화면을 억지로 채우지 않고 정보량에 맞는 폭을 갖는다.
- 긴 보조정보는 열을 추가하지 않고 셀의 두 번째 줄에 배치한다.
- 상세/수정/증빙은 action으로 분리한다.
- 골드는 브랜드, active state, primary action에 한정한다.

## v1.18 적용 범위

- Application shell
- Fund workspace shell
- 월별현황
- 공금내역
- 검수대기

나머지 공금 화면은 기능을 유지한 상태로 이후 같은 언어에 맞춰 순차 전환한다.
