# NEW AXE NET — HOME WORKSPACE 1.0

## 목적

홈은 장식용 랜딩 페이지가 아니라 `멤버 / 공금` 운영으로 들어가기 전 현재 상태를 빠르게 확인하는 첫 화면입니다.

## 이동 규칙

- 상단 NEW AXE NET 로고 클릭 → 홈
- AXE 배너 클릭 → 홈
- 배너 아래 주요 메뉴의 `홈` 클릭 → 홈
- 홈의 바로가기 → 해당 모듈/공금 섹션으로 직접 이동

## 홈 구성

### 1. 운영 요약
- 공용계좌 잔액
- 활동 멤버 / 전체 멤버
- 현재 회차 미납 / 완료 / 면제
- 관리자: 검수대기·보류
- 일반 멤버: 현재 회차 납부 완료율

### 2. 바로가기
- 멤버
- 월별현황
- 공금납부
- 관리자: 검수대기
- 관리자: 공금내역

### 3. 현재 공금
현재 선택 회차의 완료 / 미납 / 면제와 납부 완료율을 표시합니다.

### 4. 최근 공금 흐름
기존 `get_fund_recent_ledger` 데이터를 재사용해 별도 DB/SQL 없이 최근 원장 기록을 보여줍니다.

## UI 원칙

- 멤버/공금과 동일한 960px 작업 기준선 사용
- 홈만 별도 대형 카드 대시보드로 만들지 않음
- 이미 로드하는 데이터만 사용해 추가 쿼리 최소화
- AXE 골드는 공용계좌, 진행선, 선택 상태 등 핵심에만 사용
- 홈에서 실제 작업 화면까지 1~2번의 클릭 안에 접근
